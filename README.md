# Tableau Périodique

Tableau périodique interactif des 118 éléments.

**▶ Démo en ligne : [https://yoannservices.github.io/tableau-periodique/](https://yoannservices.github.io/tableau-periodique/)**

## Lancer en local

Aucune installation : ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```

puis allez sur http://localhost:8000.

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build.
